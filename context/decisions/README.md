# Operating Decisions

Decisions the workspace is currently operating under, with backlinks to the evidence that supports each one.

## What belongs here

One file per decision (`<topic>.md`). Each file is short — typically a page or less — and contains:

- **Decision** — what we're doing (or not doing).
- **As of** — date the decision was made.
- **Why** — one paragraph stating the rationale.
- **Evidence** — backlinks to the vault report(s) and/or Pulse hypothesis IDs that justify it.
- **Revisit when** — the condition that should trigger reconsideration (a falsification signal, a date, a metric threshold).

## What does NOT belong here

- Full research bodies (those live in `research/notes/`).
- Brand voice, customer profile, operating rules (already have dedicated context files).
- Decisions that haven't been made yet — those stay as Pulse hypotheses until they cross the threshold to operating.

## Provenance

Files here are typically created by the `research_briefs` directive's promotion step. See `orchestration/skills/hyperresearch_handoff.md` for the rules.
